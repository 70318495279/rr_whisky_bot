# RR WHISKY — Bot de Ofertas

1. No Telegram, abra @BotFather e envie /newbot.
2. Crie o bot e copie o token. Não compartilhe o token.
3. Adicione o bot ao seu grupo e dê permissão para enviar mensagens.
4. Configure as variáveis TELEGRAM_BOT_TOKEN e TELEGRAM_CHAT_ID.
5. Instale: pip install -r requirements.txt
6. Execute: python bot.py
